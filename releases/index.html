Agentero
poco-ai/Agentero
v0.14.0Oct 27

概要

v0.14.0 把「写作」做成与阅读并列的主画面：会议模板、Git 同步、SyncTeX 双向定位与实时预览一并落地。阅读侧新增知乎 Agent、PDF 内嵌目录编辑、字符级全文翻译与译文导出、论文库自定义属性，并修复了导入刷新、翻译预览与 PDF 阅读中的多项性能与交互问题。

新功能

  • 写作工作台与会议模板: 左侧栏在「阅读 / 写作」之间切换；thesis/ 下每个文件夹是一个项目，内置 ACL、CVPR、ECCV、ICLR、ICML、NeurIPS 官方模板，支持项目文件的重命名、移动、上传、删除与主文件设定。（commit by @JiaheChen2002）
  • Git 同步与版本历史: 将整个 thesis/ 提交并推送到 GitHub，支持手动、每次编译后或每 5/15/30/60 分钟上传；历史标签可查看每版差异并回退，回退不会删除之后的上传记录，编译产物与 PDF 不上传。（commit by @JiaheChen2002）
  • SyncTeX 双向定位: 源码到 PDF 按非空选区跨行、跨栏、跨页高亮，PDF 双击或按钮可跳回源码；后退同步优先复用最近一次点击的页内位置。（commit by @Phil-Fan）
  • 实时预览与编译面板: PDF 顶栏集中选择 LaTeX 引擎、切换实时预览与自动编译，保存源文件即触发编译；编辑器检查与编译日志合并为问题面板，可跳转到对应源码。（commit by @Phil-Fan）
  • 知乎 Agent: 内置知乎 Agent，可检索知乎直答与标题结果；论文 Info 面板可生成「去知乎提问」草稿，确认后打开知乎，对话空态改为讨论卡片。（commit by @Phil-Fan）
  • 全文翻译重排与导出: 全文翻译改为字符级重排，保护行内公式与表格文字，保留原页矢量内容，并可导出单语或双语译文 PDF。（#832 by @qychen2001）
  • 论文库自定义属性: 表头可新增 Select 属性，管理选项与颜色、在单元格中快捷赋值，并持久化列显隐、列宽与顺序；定义同时写入 properties.json 和 catalog。（#835 by @Immortal-Fates）
  • PDF 内嵌目录编辑: 在阅读器中增删、重命名、拖拽书签及其层级，选中文字即可创建书签，修改自动写回 PDF，其他阅读器也能看到目录结构。（commit by @qychen2001）
  • 订阅未读与快捷入库: 广场订阅记录条目未读状态并支持只看未读，右键即可把文章直接导入论文库。（未读 / 入库 by @Phil-Fan）
  • PDF 换页模式: 阅读 PDF 时可切换逐页翻阅，用翻页键或按钮按页移动，不再只能连续滚动。（commit by @Phil-Fan）
  • 本地 HTML 预览: 在 Markdown 中点击 HTML 链接或打开 .html 文件时，可在右侧面板预览本地页面。（commit by @Phil-Fan）
  • CLI 笔记抓取: agentero CLI 新增从 Cool Papers 抓取论文笔记并写入 NOTES.md 的能力。（commit by @Phil-Fan）
  • Agent 预设: 新增 Cursor Agent 原生 ACP 模板与 Qoder CN 预设，配置流程和版本检查同步覆盖这两个客户端。（commit by @Phil-Fan）

改进

  • 导入刷新局部化: 导入或改名论文后只刷新目标论文列表与双链，不再按论文库规模做全量重扫；800 篇库的导入后处理由多次全库扫描降为毫秒级局部更新。（#845 by @ffy6511）
  • 翻译预览增量与性能: 译文预览改为逐页重排，先译完的页优先显示；重排构建使用独立 PDFium 引擎并降低流式开销，缓解翻译时滚动卡顿。（commit by @qychen2001, @Phil-Fan）
  • 设置页重组: 整合接入与 MCP 分组，将「远程访问」重命名为「移动访问」，EasyScholar 改为 provider 卡片，移除已废弃的镜像与手动 Cookie 选项，登录关闭后自动探测机构代理。（commit by @Phil-Fan）
  • 入门引导: 本地桌面应用前置展示，新增 CLI Agent 标题与桌面端提示，并在配置 Agent 前检查 Node.js 运行时。（commit by @Phil-Fan）
  • PDF 阅读细节: 点击阅读区自动收起大纲，书签悬停操作更紧凑并显示完整标题，侧栏底部预留底栏空间，保存书签不再重载阅读器。（commit by @qychen2001）
  • 写作与编辑器打磨: 统一浮动源码工具条，CodeMirror 滚动条空闲自动隐藏，重做写作标签、上传与预览外观，并强化结构大纲层级。（commit by @Phil-Fan）
  • arXiv 源码获取: 未保存版本时下载最新 arXiv 源码，并统一 LaTeX 源码的准备与阅读流程。（commit by @qychen2001）
  • WebVPN 凭据: 登录验证后自动捕获 WebVPN Cookie，简化设置步骤并在过期时提醒更新。（commit by @Phil-Fan）

Summary

v0.14.0 turns Writing into a first-class workspace alongside Reading: conference templates, Git sync, bidirectional SyncTeX, and live preview all ship together. The reading side adds a Zhihu agent, embedded PDF bookmark editing, character-level document translation with PDF export, and custom library properties, while fixing import refresh, translation preview, and several PDF performance and interaction issues.

Features

  • Writing workspace and conference templates: Switch between Reading and Writing in the sidebar; each folder under thesis/ is a project, with official ACL, CVPR, ECCV, ICLR, ICML, and NeurIPS templates, project file actions, and main-file selection. (commit by @JiaheChen2002)
  • Git sync and version history: Commit and push the whole thesis/ folder to GitHub manually, after each compile, or every 5/15/30/60 minutes; the History tab shows each upload's diff and can restore a version without discarding later uploads, while build artifacts and PDFs stay out of the repository. (commit by @JiaheChen2002)
  • Bidirectional SyncTeX: Highlight cross-line, cross-column, and cross-page regions from source to PDF, jump back by double-clicking the PDF, and reuse the last clicked PDF position for backward sync. (commit by @Phil-Fan)
  • Live preview and compile panel: Pick the LaTeX engine, toggle live preview, and control auto-build from the PDF toolbar; saving a source file compiles it, and editor diagnostics plus compile logs share one problem panel that jumps to the source. (commit by @Phil-Fan)
  • Zhihu agent: A built-in Zhihu agent searches Zhida answers and question titles; the Paper Info panel drafts an "ask on Zhihu" question and opens Zhihu after confirmation, while the chat empty state shows discussion cards. (commit by @Phil-Fan)
  • Full-document translation reflow and export: Translation now produces a character-level reflow, protects inline math and table text, preserves original vector content, and exports monolingual or bilingual translated PDFs. (#832 by @qychen2001)
  • Custom library properties: Add Select properties from the header, manage options and colors, assign values inline, and persist column visibility, width, and order; definitions are written to properties.json and the catalog. (#835 by @Immortal-Fates)
  • Embedded PDF bookmark editing: Add, rename, remove, and reorder bookmarks and their hierarchy in the reader, create a bookmark from selected text, and write changes back into the PDF so other readers see the updated outline. (commit by @qychen2001)
  • Feed unread state and quick import: Plaza feeds track unread items and can filter to unread only, and the context menu imports an article straight into the library. (unread / import by @Phil-Fan)
  • Page-by-page PDF mode: Switch the PDF reader to page-by-page navigation and move with page-turn keys or buttons instead of continuous scrolling. (commit by @Phil-Fan)
  • Local HTML preview: Click an HTML link in Markdown or open an .html file to preview the local page in the right-hand panel. (commit by @Phil-Fan)
  • CLI note fetching: The agentero CLI can fetch Cool Papers notes and write them to NOTES.md. (commit by @Phil-Fan)
  • Agent presets: Added a native Cursor Agent ACP template and a Qoder CN preset, with setup and version checks covering both clients. (commit by @Phil-Fan)

Improvements

  • Targeted import refresh: Importing or renaming a paper refreshes only the affected paper list and wiki links instead of rescanning the whole library; on an 800-paper vault, post-import work drops from repeated full scans to millisecond-level updates. (#845 by @ffy6511)
  • Incremental translation preview and performance: Translated preview now reflows page by page so finished pages appear first, and reflow builds run on a dedicated PDFium engine with lower streaming overhead to reduce scrolling stutter during translation. (commit by @qychen2001, @Phil-Fan)
  • Settings reorganization: Consolidated integrations and MCP groups, renamed Remote Access to Mobile Access, restyled EasyScholar as a provider card, removed obsolete mirror and manual-cookie options, and added institution proxy probing after login. (commit by @Phil-Fan)
  • Onboarding: Local desktop apps now appear first, with a CLI agent heading and desktop-app hint, and Agent setup checks the Node.js runtime first. (commit by @Phil-Fan)
  • PDF reading details: Clicking the reading surface dismisses the outline, bookmark hover actions are more compact and reveal full titles, side panels reserve room for the bottom bar, and saving a bookmark no longer reloads the viewer. (commit by @qychen2001)
  • Writing and editor polish: Unified the floating source toolbar, auto-hide the CodeMirror scrollbar while idle, reworked writing tabs, upload, and preview chrome, and strengthened the structure outline hierarchy. (commit by @Phil-Fan)
  • arXiv source retrieval: Download the latest arXiv source when no version was saved, and unify LaTeX source preparation and reading. (commit by @qychen2001)
  • WebVPN credentials: Capture WebVPN cookies automatically after a verified login, simplify setup, and remind users when the cookie expires. (commit by @Phil-Fan)

Fixes

  • PDFs in the papers root: PDFs dropped directly into papers/ now get a paper folder once the file is stable, save layout results to source/layout.json, and reuse the cache after restart instead of re-parsing. (#847 by @V-IOLE-T)
  • Info previews: Intentional hover previews remain available when moving into Info and are canceled only on row exit, scroll, or editor and popover interaction, then cleared when navigation or filtering ends their context. (commit by @Phil-Fan)
  • Zhihu secret mask: Saved Zhihu credentials now appear masked in Settings instead of in plain text. (commit by @Phil-Fan)
  • Translation state: The loading state now persists until the final preview is ready, and the export action appears only when a translated PDF can be exported. (commit by @Phil-Fan)
  • Windows TeX output: Compile output is written to a temporary file before reading, avoiding pdfTeX pipe flush failures, and non-UTF-8 SyncTeX output is decoded correctly. (commit by @JiaheChen2002)
  • Fit-width PDF zoom: Fit-width zoom stays stable when the scrollbar appears or disappears. (commit by @Phil-Fan)

Resolved Issues

  • PDF bookmark editing: The reader now edits embedded PDF bookmarks and writes them back to the file. (#833 by @V-IOLE-T)
  • Local HTML preview: HTML links in Markdown preview on the right, and .html files display correctly. (#825 by @Phil-Fan)
  • Cursor Agent preset: Added a native Cursor Agent ACP preset. (#824 by @Phil-Fan)
  • CLI notes: Cool Papers note fetching is available from the CLI. (#820 by @Phil-Fan)
  • Page-by-page PDF mode: The reader supports page-by-page navigation. (#701 by @Phil-Fan)
  • WebVPN cookies: Cookies are captured automatically after login, with expiry reminders. (#742 by @Phil-Fan)
  • Library Info previews: Hover previews persist when moving into Info instead of jumping away. (#739 by @Phil-Fan)
  • SyncTeX correspondence: Fixed forward and backward positioning and highlight offsets in Writing. (#836 by @Phil-Fan)
  • Incremental translation preview: Reflow preview is now incremental per page, shortening first-screen wait time. (#838 by @Phil-Fan)
  • PDF scrolling stutter: Reflow builds now use a dedicated PDFium engine, reducing scrolling stutter during translation. (#798 by @Sonder4)

Known Limitations

  • Translated PDF quality: Author areas can still contain missing glyphs and awkward line breaks, names and terms may be mistranslated, rotated or cropped labels remain in English, and complex merged tables and formula ownership are not yet fully on par with BabelDOC. (#832 by @qychen2001)

v0.10.0Oct 26

An interrupted Attempt continues from the last completed step. --resume keeps that Attempt when result.json is absent and the lock digest matches. --resume-suite recovers an unfinished suite slot in place and still skips slots that settled as PASS, FAIL, or ERROR. A live environment that still matches the last completed step is reused. A lost environment is restored from the latest checkpoint. If the environment is still running the Attempt, the command exits 2 and does not write result.json. A settled Attempt stays immutable. This release also runs unmodified Harbor tasks, pinned git dataset sources, terminus-2, and OpenHands, and overlaps distinct sessions up to limits.agent_concurrency (omit means 1). Forking an Attempt from an earlier step has no command.

Breaking

  • Zero timeout: model.timeout: 0 and a zero request timeout fail lock. An omitted timeout stays empty on the spec. Executors fill 180 seconds from the clock table.
  • Unknown executor options: An unknown key under options fails lock and names the nearest field.

Feat

  • Resume an unsealed Attempt: Each step is appended to .ageval/runs/<attempt_id>/activity.jsonl before its effect settles, and /attempt/workspace and /attempt/home are checkpointed when the step settles. ageval run <dataset> --task <id> --resume <attempt_id> continues that Attempt. --resume-suite does the same for an unfinished slot whose activity header matches the suite, task, attempt index, and lock digest. A slot with no matching header starts a new Attempt. openai-http, anthropic-http, miniswe, and terminus-2 rebuild the next model context from the activity log. acp, OpenHands, and dsh resume the session stored under the attempt home. nooa continues from the logged transcript. Completed calls are not run again. Wall-clock time and invocation count already spent stay charged. After result.json and trajectory.jsonl exist, checkpoints/ is removed unless --keep-workspace is set. activity.jsonl stays.
  • Harbor tasks: --layout harbor locks and runs an unmodified Harbor task directory or a parent of task directories. instruction.md goes once to role solver. Scoring reads the reward file. --oracle runs solution/solve.sh and does not call the agent. ageval view opens that tree and its suite runs.
  • Git dataset refs and prepare: ageval run and ageval lock accept a pinned git source (github:org/repo@<tag|sha>, optional #<subdir>). Branch refs are rejected. ageval publish --repo registers the source on the Hub without uploading files. Declared assets are downloaded and checked by sha256. A prepare script runs only with --allow-prepare or a trusted dataset.
  • terminus-2 and OpenHands: terminus-2 runs the episode on the host and drives tmux through environment.exec. OpenHands runs the pinned SDK inside the attempt environment. Both ship as plugins with a default agent package.
  • Concurrent sessions: limits.agent_concurrency caps overlapping run-phase invokes. Omit means 1. Calls on one session stay in order. Distinct sessions overlap on acp and openai-http. The parent can cancel an in-flight invoke.
  • Collect before scoring: evaluation.collect copies declared paths before evaluator.py runs. A missing copy fails the evaluate phase.
  • Docker limits and compose: Task cpu, memory, and gpu limits apply to the attempt container. Compose can set network_mode, the main service environment, and cap_add. The attempt container is hostname main on that network.
  • ACP home entries and Node floor: $AGEVAL_HOME/acp-entries.json adds entry ids and cannot override a packaged id. The process started is the pinned package binary. An entry can declare a Node floor. The attempt image installs Node 22 when that floor is unmet. When ACP sends no usage, a declared session journal supplies the terminal counts, including on timeout and protocol error.
  • Suite pace in Viewer: A suite job can page its task table and plot task pace. Job selections stay in the address.

Fix

  • Docker file copy: Downloads that cannot be read through a bind mount use docker cp.
  • Recovery redaction: Home files are redacted before they enter a checkpoint blob. A resumed activity log uses the attempt redaction sentinels.
  • Stall clock: The phase clock stays frozen until the last overlapping stall ends. A cancelled invoke seals as invoke_cancelled.

中文

父进程在写出 result.json 之前停掉时，同一次 Attempt 从最后完成的一步继续。--resume 在锁定摘要仍然一致时保留这个 Attempt。--resume-suite 对尚未结束的槽位做同样的事，已经以 PASS、FAIL 或 ERROR 结束的槽位仍然跳过。仍与最后一步对齐的环境会被原地接回。环境丢失时，从最近的检查点恢复。环境还在跑这次 Attempt 时，命令以 exit 2 结束，不写 result.json。已经封存的 Attempt 不可改写。本版本还可以直接跑未改过的 Harbor 任务和钉版 git dataset，并接入 terminus-2 与 OpenHands。不同 session 可并行到 limits.agent_concurrency（省略是 1）。从更早的步骤 fork 出新 Attempt 还没有命令。

破坏性变更

  • 超时为 0: model.timeout: 0 和请求超时为 0 时 lock 失败。没写的 timeout 在 Spec 里仍是空，executor 按时钟表填 180 秒。
  • 未知 executor 选项: options 里的未知键会让 lock 失败，并指出最接近的字段名。

新功能

  • 续跑未封存的 Attempt: 每一步在产生外部效果之前写入 .ageval/runs/<attempt_id>/activity.jsonl，该步落定时为 /attempt/workspace 和 /attempt/home 保存检查点。ageval run <dataset> --task <id> --resume <attempt_id> 继续这一次运行。--resume-suite 对活动日志头与本次 suite、task、attempt index 和锁定摘要都匹配的未结束槽位做同样的事。没有匹配日志的槽位新开一次 Attempt。openai-http、anthropic-http、miniswe 和 terminus-2 从活动日志重建下一轮模型上下文。acp、OpenHands 和 dsh 恢复 Attempt home 里的会话。nooa 从已记录的对话继续。已经完成的调用不会再执行。已经消耗的墙钟时间和调用次数仍然计入限额。result.json 和 trajectory.jsonl 都写好之后，除非加了 --keep-workspace，checkpoints/ 会被删掉。activity.jsonl 仍留在目录里。
  • Harbor 任务: --layout harbor 锁定并运行未改过的 Harbor 任务目录，或一叠任务目录的父目录。instruction.md 交给角色 solver，只调用一次。评分读 reward 文件。--oracle 跑 solution/solve.sh，不再调用 Agent。ageval view 打开这棵树和它的 suite。
  • Git dataset 与 prepare: ageval run 和 ageval lock 接受钉版 git 源（github:org/repo@<tag|sha>，可选 #<subdir>）。分支引用会被拒绝。ageval publish --repo 只把源注册到 Hub，不上传文件。声明的 assets 会下载并按 sha256 校验。prepare 脚本只有在 --allow-prepare 或受信任的 dataset 上才会运行。
  • terminus-2 与 OpenHands: terminus-2 在本机跑 episode，tmux 经 environment.exec 驱动。OpenHands 在 Attempt 环境里跑固定版本的 SDK。两者都以插件和默认 Agent 包提供。
  • 并行 session: limits.agent_concurrency 限制 run 阶段同时进行的调用。省略是 1。同一 session 内的调用保持顺序。不同 session 在 acp 和 openai-http 上可以重叠。父进程可以取消还在进行的调用。
  • 评分前收集: evaluation.collect 在 evaluator.py 之前拷贝声明的路径。拷贝缺失时 evaluate 阶段失败。
  • Docker 限额与 compose 网络: 任务上的 cpu、memory、gpu 限额作用到 Attempt 容器。Compose 可以设置 network_mode、main 服务的环境变量和 cap_add。Attempt 容器在该网络上的主机名是 main。
  • ACP 本机 entry 与 Node 下限: $AGEVAL_HOME/acp-entries.json 可以增加 entry id，不能覆盖包内 id。启动的是钉住的包二进制。entry 可以声明 Node 下限。下限不满足时，Attempt 镜像安装 Node 22。ACP 没有送出 usage 时，声明的 session journal 提供终端计数，超时和协议错误路径上也保留。
  • Viewer 里的 suite 节奏: suite 的任务表可以翻页，并画出每题耗时。Jobs 里的选择留在地址栏。

修复

  • Docker 拷文件: 绑载读不到的下载改走 docker cp。
  • 恢复时的脱敏: home 里的文件在进入检查点之前脱敏。续跑重新打开的活动日志使用这次 Attempt 的脱敏标记。
  • 等待时钟: 阶段时钟停到最后一段重叠等待结束。被取消的调用封存为 invoke_cancelled。

ageval
ZJU-REAL/ageval
v0.9.0Oct 14

Profiles bind one nested model object. A string model, or a flat model key on options, fails lock. A failed executor invoke waits on options.upstream_stall_seconds (omit means 3600 seconds; 0 turns the wait off) without charging that wait to the phase clock. After the run, ageval results analyze writes a read-only report, ageval results regrade scores harvested artifacts again, and --retry-errors re-runs ERROR slots on resume. Hub can queue a hosted suite on e2b or daytona. That worker does not start Docker. An analysis report does not change PASS and is not uploaded to Hub.

Breaking

  • Nested model: A profile model is an object: id, api, reasoning.effort, timeout, watchdog, extra. A string model, or a flat key on options (api, reasoning_effort, timeout, request_timeout, watchdog, extra_body), fails lock. Omitting model is still valid. An omitted leaf is not sent. timeout is the HTTP clock. watchdog is the abort clock; when omitted, the spec stays empty and the executor applies its own finite default (180 seconds for miniswe). --model writes this run’s model.id. api: chat sends effort as top-level reasoning_effort. api: responses sends reasoning.effort and posts /responses, with no fallback to chat. Lock rejects an api, field, or extra key the executor does not allow. A factory that is not a BaseExecutor warns, and fails lock when AGEVAL_STRICT_MODEL_CONTRACT=1.

Feat

  • Upstream stall: When an executor invoke is not ok and the result can be retried, the parent waits for options.upstream_stall_seconds and sends the same invoke again. Omit means 3600 seconds; 0 turns the wait off. The interval is 60 seconds and is not a field. The phase clock stays frozen, progress shows upstream_stall, and evidence records one fact of that name. The wait does not consume another agent_invocations count. ACP does not replay a prompt that already changed the workspace: it records not_repeatable and does not wait. miniswe retries the current in-process model query, and the parent does not start another agent after that inner budget is spent. A refusal before the executor runs (wall clock already exhausted, invocation quota already exhausted, redaction failure, offline forced) fails once and does not stall.
  • Post-run analysis: ageval results analyze writes analysis/<analyzer>/report.json for one run (--run) or one suite (--suite-run). A suite also writes summary.json. The default analyzer is stats. hack and review can call an installed openai-http or anthropic-http package; pass --agent, and --model when that package has no model. The report does not change PASS or evaluation/checks.json, and it is left out of Hub packs and live share. The local Viewer adds an Analysis evidence tab when the report exists.
  • Retry ERROR and regrade: --retry-errors requires --resume-suite. ERROR slots in this filter run again. PASS and FAIL stay skipped. Each retry is a new Attempt, and the old row stays on previous[]. ageval results regrade copies the source task-artifacts/ into a new Attempt and runs evaluate with the current dataset lock. The agent does not start. The source result.json stays. A missing or mismatched harvest is ERROR (regrade_harvest_missing). Trajectory text is not a verdict.
