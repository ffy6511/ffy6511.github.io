摘要

缩短复杂 PDF 的首屏高清渲染与框选等待，修复重复原生链接累积造成的长时间停顿，以及连续切换 PDF 时异步文档未释放的既有问题。

场景

AgentCompass 等复杂 PDF 打开后，首屏和框选可能长时间等待；连续切换文档后，还可能出现 Failed to allocate ... bytes。

本次包含四项改动：

  • 高清瓦片（#871）：将瓦片从 768 调整为 512 CSS px，缩短单次不可抢占的光栅任务。缩放、像素密度、重叠边界和现有取消机制保持原策略。
  • 可见页面优先（#871）：仅为进入视口的页面请求整页底图，避免屏外重页以更高优先级排在可见瓦片和框选裁剪之前；已有底图缓存继续复用。
  • 链接判重（#872）：对没有 transfer context 的 LINK，忽略顶层瞬态 id，按其余完整内容判重。目标、位置、样式和备注的差异仍保留，普通用户高亮不按内容合并。
  • 文档释放（#873）：为 Document Manager 增加 ESM / CJS 补丁。加载中关闭时等待打开任务结算，再释放迟到的文档；合并重复关闭请求，保留其他 pane 的引用。该生命周期缺口在 main 已存在。

旧批注文件打开时在内存中判重，正常保存后收敛；不重写源 PDF。

What is this for

A recorded coding run can hide a tool or environment failure if the operator calls the model again. Operators need to execute the recorded terminal actions again in a fresh environment, see the first meaningful difference, and optionally grade the new artifacts. Replay completion must not become PASS by itself.

Implementation

  • ageval replay <dataset> --run <attempt_id> reads the retained recovery bundle (activity.jsonl, checkpoints/, and replay-input.json, kept by --keep-recovery-state). It refuses before any environment starts when the bundle, arguments, or task/image identity cannot be reconstructed.

  • Upload stores that object on the attempt row. Viewer and Hub show a replay marker. Default pass@k skips replay rows.

feat: promote canary — fork a retained checkpoint under a new model
ZJU-REAL/ageval
#325Oct 27

What is this for

A settled Attempt dropped activity.jsonl and checkpoints/ with the workspace, so there was no way to continue a finished run-phase cut under another model. --resume only continues an unsealed Attempt in place, and a settled Attempt stays immutable.

This canary slice keeps that recovery bundle on request, lists which cuts can be forked, and starts a new Attempt from one cut. The parent environment is left alone. The child keeps the source task, harness, and environment kind, and may change the solver model.

Implementation

  • After result.json and trajectory.jsonl both exist, Core deletes activity.jsonl and checkpoints/ together unless --keep-recovery-state or AGEVAL_KEEP_RECOVERY_STATE retains them. The CLI flag wins. An unsealed Attempt always keeps the bundle, so --resume does not need the flag. --keep-workspace retains the box work root and <attempt>/state only.
  • ageval checkpoints <dataset> --run <attempt_id> reads the retained bundle and does not start an environment. Each row has seq, phase, blob state, and forkable. A non-forkable row includes a reason. A missing Attempt or bundle exits 2.
  • ageval run --fork <source> --checkpoint <seq> --model <id> mints a new Attempt and a fresh environment. It does not attach or write the parent. --fork is exclusive with --resume. --agent and --profiles are rejected. Core re-locks from the source job overlay and applies only the solver model override (id, api, timeout, watchdog, reasoning/effort).
  • Continuation is miniswe, terminus-2, openai-http, or anthropic-http. Anything else fails with continuation_unsupported before the environment starts. The child copies the activity prefix through the selected seq and the selected checkpoint blobs. Later parent events are not copied.
  • Inherited events are evidence, not new child calls. They do not restore invocation quota, do not charge parent phase time, and replay at cost 0. Shared-prefix usage is summed separately on fork.shared_prefix_usage.
  • The child writes fork (ageval.fork/1) on result.json and summary.json: parent Attempt, checkpoint seq, source and child lock digests, and the model change. Registry stores that object on the attempt row. Default pass@k and from-scratch rollups skip rows that carry fork.
  • A completed-invoke fork returns the old result and writes no new events. The seal copies the parent display trajectory and marks those rows inherited. A cut inside the invoke does not copy later parent lines.
  • Viewer and Hub show a short fork tag after the model name. Hover lists the source model, the continuation model, the checkpoint seq, and the parent Attempt. The trajectory draws a cut after the inherited prefix. A click inside the tooltip does not open the row.

feat(runtime): recover an unsealed Attempt in place
ZJU-REAL/ageval
#319Oct 26

What is this for

An Attempt that dies before result.json is written (killed parent, reboot, dropped session) has already spent model turns and tool calls. --resume-suite treated that slot as unfinished and allocated a new Attempt, so the interrupted directory was discarded. trajectory.jsonl is sealed only in record, so it cannot drive recovery. Session and request ids were random, so a restarted run.py could not line up with the previous process.

Implementation

  • .ageval/runs/<attempt_id>/activity.jsonl (ageval.activity/1) is the parent-owned pre-effect log. A truncated final line is dropped. A broken middle line seals activity_log_corrupt. .ageval/runs/<attempt_id>/checkpoints/ (ageval.checkpoint/1) stores content-addressed snapshots of workspace, home, and artifacts. Keyless auth paths stay out of blobs/. Home text is redacted before it is hashed. checkpoints/ and <attempt>/state are removed after seal unless --keep-workspace is set.
  • EnvironmentProvider gains runtime_handle, probe, and attach. Recovery files live at /tmp/.ageval-state (host <attempt>/state for local and docker). A live environment whose nonce and cursor match is reused. A missing or diverged environment is stopped best-effort and rebuilt from the latest checkpoint. e2b, daytona, and ssh upload the restored tree and tee command output into last_exit.json.
  • --resume <attempt_id> continues one unsealed Attempt when the lock digest matches. --resume-suite recovers a matching unsealed slot in place and still skips slots that already settled. A still-busy environment exits 2 and does not write result.json. A settled Attempt stays immutable.
  • openai-http, anthropic-http, miniswe, and terminus-2 rebuild context from the activity log. acp, acp-oneshot, OpenHands, and dsh resume the native session under /attempt/home. nooa has no session and continues from the logged transcript. Completed calls are not run again. Wall-clock time already recorded on completed steps stays charged, and an already admitted invoke does not consume another invocation.
  • seal_run is recorded after artifact harvest. Resume skips run only when that phase is complete and every declared artifact is present. README shows the framework figure and these resume commands.

feat(runtime): lock and run unmodified Harbor tasks
ZJU-REAL/ageval
#310Oct 21

What is this for

ageval only locked native dataset packages (ageval.yaml + task.yaml + run.py + evaluator.py). Harbor tasks use a different tree (task.toml, instruction.md, environment/, tests/test.sh). There was no supported way to point ageval run at an unmodified Harbor task or task-set.

Summary

--layout harbor is an explicit intake switch on lock, run, and tasks. Omit it and existing ageval packages behave as before. A Harbor tree is locked into a normal ageval attempt: the built-in runner sends instruction.md, and the built-in scorer turns tests/test.sh plus reward.json / reward.txt into PASS, FAIL, or ERROR.

Implementation

  • Single task directory: task.toml plus instruction.md, tests/test.sh, and environment/ or environment.docker_image. --task is rejected.
  • Implicit task-set: a parent whose immediate children are Harbor tasks. Omit --task to run the suite; repeat --task to filter. Task id is the directory name. [task].name must match that name when present.
